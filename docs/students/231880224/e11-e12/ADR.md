# ADR：真实项目适配与报告版本校验

状态：已实施（2026-11-17）

组内既有 `fixtures/md-rd` 为单源 C/Make；E11/E12 当前接口只接受 `main.c`、`helper.c`、`config.h` 与显式 Make 规则。为在不改动 E7/E8 既有检查的前提下跑通组内数据，本次从该 fixture 派生独立双源项目，保留 C0 基线与 C1 故障提交，并作为独立数据集与课堂生成样例分开记录。

报告消费前依次校验外层 `schema_version`、`kind`、`status`、`commit`，以及内层 `data.commit`；任一不符立即返回 `STALE_REPORT` 并停止后续修复。补丁验证在独立副本执行，失败时恢复原始 Makefile。

候选 Dockerfile 沿用课程镜像的 Debian 镜像源替换（清华源 + IPv4），避免课程服务器访问官方源超时导致 DRAFT 失败。

代价：派生项目仍是教学规模，不能代表复杂真实仓库；E8 的全局缓存键使任一源文件指令变化都刷新全部目标，增量收益在源文件改动时退化为全量。后续可为更复杂组内项目增加按目标缓存键与目标路径映射。
