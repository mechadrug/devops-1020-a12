# ADR：个人贡献放在交接与部署边界测试

2026-11-23，李玄同 231880224。

## 决策

个人贡献不修改主责已实现的三项修复，而是在 `labs/e13e14/tests/` 新增独立合同测试，覆盖交接边界（URI 逃逸、跨 job 产物、重复阶段、摘要格式）和部署身份结构（UID/GID、socket 归属、端口、健康检查、资源上限），并另做一次个人检测回归和四服务固定样例运行。

## 理由

主责的 #17/#19/#20 修复已有实现和测试；重复修改同一路径既容易冲突，也不能增加独立验证。个人价值在于从接收方和部署方视角验证“错误输入不会进入构建/修复”和“非 root 与隔离配置不会被悄悄改回”。测试失败会直接暴露回归，不需要改动生产代码。

## 后果

- Compose 契约测试基于文本结构；若后续重构 compose 字段（例如改用 YAML 锚点外置），需要同步更新测试，否则会误报。
- 文本测试不替代运行时验证；本人另跑了四服务固定样例、抓取四角色日志并扫描，二者互补。
- 测试只证明当前分支的结构与边界行为，不证明 B12 远端执行或 A/B 实际项目；这些仍由主责与 B12 完成。

## 边界

- 不签 B12，不把本地彩排写成远端签收
- 不创建或移动 `v0.9-rc`
- 不修改分配主机的 doctor 内存阈值
