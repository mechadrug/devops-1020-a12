## 来源、范围与协作

`scan()`、`fixture()`、`buildchecker()` 等核心实现来自课程导入；胡凌岳的三项测试来自已合并 PR #10。本次只增加测试、可重复的个人扩展脚本和个人文档，没有将参考算法改写后冒充自己的新算法。测试和文档由 Codex AI 辅助生成、运行和核验，详细分工见 AI_USAGE.md。

本实现以所有本地 C/H 的预处理行、文件集合、Make 配方、受限 CFLAGS 和编译器版本构造缓存 key。相同 key 可复用 actual，声明图和 findings 每次重算；key 改变则保守刷新全部目标。它没有实现论文完整的增量系统调用归并、任意 Make 规则和复杂编译配置推断。增量与全量路径共用 scan 实现，所以再用真实 BuildChecker 作独立采集路径核对仍很必要。

个人 PR、最终 head SHA、对应 Actions run/headSha/artifact 及合并记录将在课程包 `SUBMISSION.md` 中按 GitHub 实际记录补全；本报告的性能与实验数值均来自本人目录，不引用教师示例计时或他人 work 作为个人证据。
