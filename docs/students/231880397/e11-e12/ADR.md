# ADR：A12 项目适配与报告版本校验

状态：已实施（2026-11-15）

A12 已有 `fixtures/md-rd` 是单源 C/Make，E11/E12 当前接口仅支持 `main.c`、`helper.c`、`config.h` 和显式规则。为在不改变旧 E7/E8 检查的情况下跑通组内版本，本次从该 fixture 派生独立双源项目，并保留源提交、适配提交与故障提交。课堂生成样例和此项目分别记录。

报告消费前校验外层 schema、kind、status、commit 和可用的内层 data.commit；发现版本不符立即返回 STALE_REPORT。补丁验证仍在独立副本进行。候选 Dockerfile 使用与课程镜像相同的 Debian 镜像源，以避开课程服务器上官方源下载超时。

代价：派生项目仍是教学规模，且 E8 的全局缓存键使源文件指令变化刷新两个目标；后续可为更复杂组内项目增加按目标缓存键和目标路径映射。
